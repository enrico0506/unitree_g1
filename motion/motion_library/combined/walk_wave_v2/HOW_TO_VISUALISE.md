# How to visualise: walk_wave_v2

Live interactive MuJoCo window, name-based lookup:

```bash
python motion/motion_library/view.py walk_wave_v2
```

Or point directly at the npz (works from any script, not just this helper):

```bash
python motion/motion_builder/combined/walk_and_wave/scripts/view_npz.py motion/motion_library/combined/walk_wave_v2/walk_wave_v2_holomotion.npz
```

List every motion available in the library:

```bash
python motion/motion_library/view.py --list
```
